# Print Name N Times

## Problem
Print the name "Abi" N times using recursion.

## Approach
- Take N as input.
- If N becomes 0, stop the recursion.
- Print the name.
- Call the function again with N - 1.

## Time Complexity
O(N)  -> because N times call then function

## Space Complexity
O(N) --> because every recursive fun call is stored in the stack. so Space complexity O(N)
