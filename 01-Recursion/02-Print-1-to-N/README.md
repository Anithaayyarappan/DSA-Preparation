# Print 1 to N

## Problem

Print numbers from 1 to N using recursion.

## Approach

* Take N as input.
* If N becomes 0, stop the recursion.
* First, call the function with N - 1.(because we want 1 to n so 1st fun call)
* Then, print the current value of N while returning from recursion.

## Time Complexity

O(N)

## Space Complexity

O(N)
