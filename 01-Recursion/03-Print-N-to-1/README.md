# Print N to 1

## Problem

Print numbers from N to 1 using recursion.

## Approach

- Take N as input.
- If N becomes 0, stop the recursion.
- Print the current value of N first (because we want the output from N to 1).
- Then, call the function with N - 1 to print the remaining numbers in decreasing order.

## Time Complexity

O(N)

## Space Complexity

O(N)
